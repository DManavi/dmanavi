## About

I design and build maintainable software with a focus on strong contracts, clear boundaries, and production-ready developer experience. My public work spans multi-provider infrastructure, type-safe libraries, serverless application patterns, and API tooling.

- Building self-hosted services that remain simple to operate
- Designing strongly typed abstractions for APIs and event-driven systems
- Packaging reusable solutions for npm, Packagist, Docker, and the CLI
- Prioritizing testing, static analysis, automation, and clear documentation
